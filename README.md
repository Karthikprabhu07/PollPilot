# Poll Pilot 🗳️

Poll Pilot is a premium, nonpartisan global election education assistant designed to provide civic intelligence for every democracy.

## Features

- **Multi-language Support**: Available in over 20 languages including English, Hindi, Tamil, Telugu, Spanish, French, and more.
- **AI-Powered Chat Assistant**: Ask questions about voter registration, polling stations, election rules, and candidates.
- **Civic Roadmap**: Step-by-step guidance for voters:
  1. Registration
  2. Learn Issues
  3. Polling Place
  4. Cast Your Vote
  5. Track Results
- **Authentication**: Secure user authentication provided by Clerk.

## Technologies Used

- **React** (v19)
- **Vite**
- **Firebase**
- **Clerk** (for Authentication)

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```
